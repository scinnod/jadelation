Dieser Service bietet einen einfachen Zugang zum Übersetzungsdienst DeepL aus dem Jade-Intranet über ein einzelnes *DeepL API Pro*-Abonnement. Im Gegensatz zu den kostenlosen Diensten von DeepL, z.B. auf der Website, werden Anfragen mit diesem kostenpflichtigen Abonnement sorgfältiger behandelt und nicht von DeepL zur Schulung von KI-Übersetzungsmodellen verwendet.Die Nutzung ist daher auch für die Übersetzung interner und personenbezogener Informationen möglich, die möglicherweise schützenswert sind.
