# About This Service

This service provides translation capabilities powered by DeepL.

---

**Customize this content** by editing the markdown files in `data/about/`:
- Create or edit `about_en.md` for English
- Create or edit `about_de.md` for German  
- Create `about_XX.md` for other languages (replace XX with language code)

The system will automatically display the content matching the user's language preference, or fall back to English if not available.
